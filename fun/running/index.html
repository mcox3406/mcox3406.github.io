Methods and data coverage

Dates and clock times remain local to each activity. Separate activities retain their original IDs, including multiple runs on one day.

Running intervals are estimated from local start time plus moving duration. Exact pause timing is unavailable. Intervals crossing midnight are split, and overlapping intervals count once. Probability is occupied time within each 15-minute interval divided by available time across fully covered dates, including dates without runs. Today and dates with incomplete coverage are excluded from probability and weekday averages.

Total distance includes all imported runs in the selected year through today. Complete coverage means the exporter reports retrieving every running activity for that date; the page cannot independently verify this claim. Dates without coverage are unknown. Weekly bars distinguish partial weeks and incomplete coverage.

Imported files are stored in this browser. Export a snapshot to retain a copy. Updating the site's default history requires replacing the activity snapshot in the repository.

JSON and CSV formats

JSON snapshots include local date coverage for the probability and weekday-average plots. Replace the template's example records and remove its demo flag when using verified history. Existing activity snapshots and planner backups with activity history are supported.

CSV files use the template's meter and second columns. They have no coverage declaration, so probability and weekday averages are unavailable. Convert native exports to this format before importing, resolving units and timezones at the source.
