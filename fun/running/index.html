A note on the numbers

These are descriptive views of recorded running activities. Dates and clock times stay local to each activity, including when traveling. Each activity keeps its own ID, so doubles remain separate.

The clock estimates a continuous running interval from each local start plus its moving duration. Exact pause timing is unavailable. Intervals crossing midnight are split, and overlapping intervals count once. The plotted probability is the fraction of minutes spent in these estimated intervals within a 15-minute clock window, averaged over fully covered dates. It describes this history; it is not a forecast. Today, future dates, and dates with unknown coverage are excluded from probability and weekday averages.

Total distance and the run list include all imported runs in the selected year through today. Coverage is the exporter's claim that all running activities for a date were retrieved; the page cannot independently verify it. Unknown dates do not establish rest days. The calendar and weekly bars distinguish incomplete coverage.

Imports stay in this browser. Export a backup to retain them. To share your history on the public site, replace the site's activity snapshot in the repository with a reviewed export.

JSON and CSV formats

JSON snapshots include local date coverage, so they can support the probability plot. Replace the template’s example records and remove its demo flag when using verified history. Existing activity snapshots and planner backups with activity history are supported.

CSV files use the template's explicit meter and second columns. They have no coverage declaration, so the clock and weekday averages stay unavailable. Convert native exports to this format before importing; a missing timezone or ambiguous unit should be resolved at the source.
